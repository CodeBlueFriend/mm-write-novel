# 故事架构

## 核心发现

故事必须回答：谁想要什么、为什么现在行动、谁阻止、失败失去什么、选择如何造成下一局面、最终回答什么。使用 1 个主类型、1 个次类型、1—3 个核心 trope 和 1 个差异化维度，避免标签堆叠。

故事引擎由“持续欲望 + 可变阻力 + 有代价的选择 + 不可逆结果”组成。删除任一关键事件后，若后续仍无条件发生，说明因果链是假连接。

## 多线同步

总结构同时标注：事件主线、人物弧、核心关系、秘密揭示、伏笔回收、情绪曲线和类型承诺兑现。支线至少完成压力测试主角、推进主题、改变关系、提供资源/阻力、揭示规则或汇入结局中的一项。

故事线状态：`planned / seeded / active / paused / converging / resolved / abandoned-approved / orphaned`。`orphaned` 是错误。

## 卷与篇章弧

每个弧具备起始状态、目标、阻力、升级、中段变化、高潮选择、不可逆结果、人物/关系变化、伏笔动作和下一入口。升级要改变选择空间，而不只是提高音量。

## 结局设计

结局必须由前置选择、规则和证据支持，同时完成事件结果、人物选择和主题回答。自然完结条件应在开书阶段定义；系列入口不能替本卷逃避收尾。
