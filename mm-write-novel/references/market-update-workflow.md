# 市场资料更新

市场资料字段：平台、市场、来源类型、URL、发布日期、观察日期、到期/复核日期、可观察信号、编辑推断、稳定性、置信度、适用模式和状态。

## 更新流程

1. 打开原始链接，优先平台官方页；记录页面标题和日期。
2. 区分分类、榜单、政策、征文和编辑偏好。
3. 将直接可见内容写为“信号”，分析写为“推断”。
4. 标记 `stable / trend / temporary` 与 `active / pending / expired / disabled`。
5. 榜单至少交叉观察热门、新书/上升、完结/长期口碑、官方活动、分类入口和治理边界。
6. 只提炼欲望、冲突速度、主角类型、视角、章节长度、情绪曲线和规模等抽象规律。
7. 检查是否与项目主题、人物或锁定事实冲突；趋势永不静默覆盖上层规则。

快照放入带日期的目录；长期平台文件只保留稳定特征，并链接快照作为证据。
