# 作者声纹与去 AI 味

模拟成熟作者的观察、选择、试写、删减和复审过程，不假装真人身份。声纹只来自用户作品、抽象风格维度或用户认可样章；不得复刻在世作者的可识别文风。

## 重点检测

- 人人同句法、同价值判断；
- 段段总结、频繁整齐对照；
- 情绪只有命名，没有身体、行为和选择；
- 泛化感官、抽象名词和形容词堆叠；
- 过度解释动机、重复已知信息；
- 对话完整礼貌、轮流发言；
- 每章同一结构与同一种钩子；
- 伏笔被反复高亮；
- 无来源金句；
- 机械加入错字、俚语或口头禅。

## 修订顺序

POV/距离 → 欲望/信息边界 → 删除重复 → 抽象情绪转为具体选择 → 区分人物语言 → 调整句段 → 校准人物来源的意象 → 朗读 → 对照声纹 → 复查事实。

声纹稳定不等于所有章节平均句长和段落形状相同；POV、年龄、关系和场景强度应带来自然变化。
