# 中文平台总览

平台是消费与分发方式，不是题材本身。先锁定故事承诺，再选择表达方式。

| 平台 | 常用场景 | 适配重点 |
|---|---|---|
| 番茄 | 短故事、中长篇免费连载、IP 向 | 快速进入、持续追读、阶段兑现、稳长线 |
| 知乎盐言 | 短中篇 | 高概念入口、叙述可信、信息控制、公平反转 |
| 微信读书 | 精品网文、出版小说、长尾阅读 | 完整度、人物厚度、文字品质、可重读性 |
| 掌阅 | 类型长篇、付费阅读 | 类型承诺、稳定升级、分卷结果、商业结构 |
| 七猫 | 免费类型长篇 | 清晰冲突、具体情绪回报、持续更新、自然完结 |

提交前联网核验分类、政策和活动。平台中立模式优先作品完整性和可迁移性。
